# 資產負債表（formNo 4）：無形資產與「所含商譽金額」要放在同一列

整理日期：2026-11-11。對象：`/ael/peit/form/metadata`（formNo 4，資產負債表，taxYear 114，staging 實測）。
對照紙本：`public/form-previews/cit-balance-sheet.webp`。

## 問題

紙本 1510 那一列是一行字，商譽金額直接填在標題裡的空格：

> 1510　無形資產（包括商譽金額 ＿＿＿＿ 元）

staging 實測：

| 欄位 | `fieldCode` | 現況 |
|------|-------------|------|
| 無形資產 | `BS_1510`（`officialFieldCode: "1510"`） | `layout: row`、`labelTemplate: null` |
| 無形資產所含商譽金額 | `BS_1510_GOODWILL`（`officialFieldCode: null`） | `layout: row`、`parentFieldCode: BS_1510`、`labelTemplate: null`，在 `fields[]` 排第 90，離 1510 很遠 |

所以畫面上它是區塊最下面獨立的一列「無形資產所含商譽金額」，與 1510 隔很遠。

## 需要後端調整（依 `開帳文件修改.md` G1：`layout: inline`、`labelTemplate`、`parentRowCode`）

1. `BS_1510_GOODWILL`：
   - `layout` 改為 `"inline"`
   - `parentRowCode` 設為 `BS_1510`（`parentFieldCode` 維持 `BS_1510`）
2. `BS_1510`：`labelTemplate` 設為
   `無形資產（包括商譽金額 {{field:BS_1510_GOODWILL}} 元）`（`displayName` 維持「無形資產」）。
3. `BS_1510_GOODWILL` 不需要在 `fields[]` 排在 1510 旁邊（它嵌進 1510 的標題裡），但請維持值的讀寫與送出不變。

## 前端處理

前端已支援資產負債表列的 `labelTemplate`：標題裡的 `{{field:}}` 畫成嵌在文字中的輸入框，
被模板引用的欄位不再單獨成列。後端補上以上兩點後不需再改前端；補上之前畫面維持現狀（獨立一列）。

# 資產負債表：標示紙本填在「合計」欄的科目（標題粗體）

## 問題

紙本金額分「小計」「合計」兩欄。有些科目沒有子科目、也不是算式欄位，但紙本是填在**合計欄**，與區塊標題同一層，
例如 3300 資本公積、3600 減：庫藏股票（紙本以（）表示，填在合計欄）。這類科目畫面上標題要粗體，與小計、合計列一致。

staging 實測（formNo 4，taxYear 114）這兩個欄位：

| 欄位 | `parentFieldCode` | `isSubtotal` | 有子科目 |
|------|-------------------|--------------|----------|
| 3300 資本公積 | `null` | `false` | 否 |
| 3600 減：庫藏股票 | `null` | `false` | 否 |

與 3100、3400、3500（`isSubtotal: true`、有子科目、同在合計欄）在 metadata 上沒有任何可區分「填在合計欄」的標記。
目前前端暫時用「沒有父科目 → 粗體」判斷，只是推測，換年度或後端增減科目時可能不準。

## 需要後端調整

1. 新增布林屬性 `isTotalColumn`（暫定名稱，可後端決定）：紙本印在「合計」欄的科目為 `true`，其餘（小計欄）為 `false` 或省略。
   至少包含 3300、3600，以及紙本所有填在合計欄的科目（如 1100、1130、1140、1190、1200、1400、1900、1000、2100、2130、2136、2190、2200、2000、3100、3400、3430、3500、3000、9000 等，請依紙本確認）。
2. **不要為此把這些欄位標成 `isSubtotal: true`**：`isSubtotal` 的欄位前端視為「合計列、不送期初餘額明細」，
   3300、3600 是使用者填寫的科目，要照常存取與送出。

## 前端處理

後端提供 `isTotalColumn` 後，前端改依它決定粗體，取代目前「沒有父科目」的推測；
3300、3600 的值照常儲存與送出（3600 減項以負值儲存，見規格的減項處理）。
