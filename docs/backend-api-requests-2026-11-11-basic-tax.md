# 營利事業所得基本稅額申報表（formNo 3）：表頭要在表單最上面

整理日期：2026-11-11。對象：`/ael/peit/form/metadata`（formNo 3，營利事業所得基本稅額申報表，紙本 `*0200*`）。
對照紙本：`public/form-previews/cit-amt.webp`。

## 問題

紙本最上方是表頭：所得期間、「本營利事業符合背面附註一述條件，非本申報表適用對象，免填寫本申報表」勾選、營利事業名稱、統一編號。
staging 實測畫面：這幾個欄位（所得期間、非本申報表適用對象免填、營利事業名稱、統一編號、收件編號）出現在整張表最下面，
在基本所得額計算、前 5 年損失明細表、基本稅額與一般所得稅額之差額計算之後。

前端區塊順序依「區塊第一個欄位在 `fields[]` 出現的位置」（規格 G1／G5），不自行調整，所以需後端修正。

## 需要後端調整

1. 表頭欄位在 `fields[]` 排到最前面，順序為：
   所得期間（起、迄）→ 非本申報表適用對象免填（勾選）→ 營利事業名稱、統一編號 → 收件編號。
2. 表頭區塊維持無標題（`sections[].title` 為 `null` 或不回傳該區塊）。
3. 收件編號放在表頭區塊內（每一份文件的收件編號都在表單最上方）。

其他文件的表頭排序見 `backend-api-requests-2026-11-11.md` 最後一段（12 份通用），本文件只補基本稅額申報表的欄位順序。
