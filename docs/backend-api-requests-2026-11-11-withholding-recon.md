# 各類給付扣繳、股利憑單金額與申報金額調節表（formNo 7）：與紙本不一致處

整理日期：2026-11-11。對象：`/ael/peit/form/metadata`（formNo 7，taxYear 114，staging 實測）。
對照紙本：`public/form-previews/cit-wh-recon.webp`（紙本 `*0800*`，第 8 頁）。

## 1. 表頭要在表單最上面

實測 `fields[]` 順序：表一、表二、表三、表四（`RELATED_*`）的欄位 → `HEADER`（`HDR_VAT_NO`、`HDR_RECEIPT_NO`）→ `PAY_NOTE`（說明 1、2 內嵌的三個金額欄位）→ 表三小計列格子。
所以表頭（統一編號、收件編號）出現在整份表單最下面。

請後端把 `HEADER` 欄位移到 `fields[]` 最前面（維持無標題），收件編號每份文件統一在表頭內，見 `backend-api-requests-2026-11-11.md` 最後一段。

## 2. 表四「揭露情形 1～4」的名稱與紙本不同

`RP_DISC_OFFSHORE`、`RP_DISC_TAX_CREDIT`、`RP_DISC_LOSS_CARRY`、`RP_DISC_REV_300M` 目前的 `displayName`：

| 欄位 | 現況 | 紙本 |
|------|------|------|
| `RP_DISC_OFFSHORE` | 揭露情形1：境外有關係人 | 在中華民國境外有關係人（包括總機構及分支機構）。 |
| `RP_DISC_TAX_CREDIT` | 揭露情形2：租稅優惠實際抵減超過五十萬元 | 依租稅減免法規享有租稅優惠〔係指當年度營利事業所得稅結算申報書（租稅減免部分）所列之法規〕，且依法申報實際抵減當年度營利事業所得稅結算申報應納稅額及前 1 年度未分配盈餘申報應加徵稅額之金額合計超過 50 萬元者。 |
| `RP_DISC_LOSS_CARRY` | 揭露情形3：扣除前十年虧損超過二百萬元 | 依法實際申報扣除前 10 年虧損之金額超過 2 百萬元者。 |
| `RP_DISC_REV_300M` | 揭露情形4：收入總額在三億元以上 | 1.～3.以外之營利事業，全年收入總額在 3 億元以上。 |

請 `displayName` 改成紙本文字（去掉「揭露情形N：」前綴，編號 1～4 已在 `officialFieldCode`），
前端會把編號顯示在文字前面。

## 3. 表四「揭露情形 1～4」的位置：要在「二」那題的 是／否 後面

紙本表四「二、關係人及關係人交易揭露標準」的結構是：

> □是 □否：本營利事業當年度結算申報之全年營業收入淨額及非營業收入合計數（以下簡稱收入總額）在 3 千萬元以上且符合下列情形之一：【…】
> 　1.□…　2.□…　3.□…　4.□…

實測 `RP_DISC_OFFSHORE`、`RP_DISC_TAX_CREDIT`、`RP_DISC_LOSS_CARRY`、`RP_DISC_REV_300M` 的 `sectionCode` 是 `RELATED`（表四最上層區塊），
且在 `fields[]` 排在表四所有欄位的最前面，所以畫面上這四個勾選出現在整個表四最上方，在「一」「二」的標題之前。

請後端調整：

1. 這四個欄位的 `sectionCode` 改為 `RELATED_2`（「二、關係人及關係人交易揭露標準」區塊）。
2. 在 `fields[]` 排在 `RP_DISC_YES`、`RP_DISC_NO`（`RP_DISC` 勾選組）之後。

同理 `REL_EXEMPT_REV_30M`、`REL_EXEMPT_INT_4M`、`REL_INTEREST_TOTAL`、`REL_EXEMPT_LOSS`（2-1、2-2、2-3）目前在 `RELATED_1` 區塊，
排在第 2 題（`REL_EXEMPT_YES`／`NO`）之後，位置正確，不用改。

## 前端處理

- 是／否題改成紙本的樣式：勾選框在題目前面同一行（□是 □否：題目），題目後接括號說明。
- 勾選項有紙本編號（2-1、2-2、2-3、揭露情形 1～4）時，編號顯示在勾選框前面。
