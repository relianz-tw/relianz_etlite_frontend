# 開帳文件修改

開帳設定共 12 份文件，各表 metadata 需要後端調整的項目依 formNo 列於下方。

## 全域規格（開帳 12 份文件通用）

- `dataType` 新增「百分比」類別（`6`），所有表單的 % 欄位統一使用。
- 百分比允許負值。
- 數值用顯示值（20 代表 20%，-5 代表 -5%）。
- **金額欄位（`dataType: 1`）一律允許正負值**（例如「其他」調整欄、虧損、所得額、差額）。回傳 metadata 與**儲存／確認的 API** 都要支援負值：不得拒絕、不得取絕對值、不得轉成 0，驗證與型別（含資料庫欄位、JSON 序列化）都要能存取負數；算式（`formula`）依帶符號的值計算。前端所有金額輸入都開放輸入負號。
- **日期起訖 group**：成對的起迄日期（如「所得期間起／迄」）在 metadata 頂層回傳 `dateRanges[]`，所有表單統一套用。
  - 辨識規則：同一個 `sectionCode` 內，`dataType: 3`（日期）且 `fieldName` 為「○○起」「○○迄」同名前綴的兩個欄位。
  - 起、迄兩個欄位仍留在 `fields[]`，`fieldName` 與值的讀寫不變，`dateRanges[]` 只負責標示兩者是一組。
  - 驗證由後端負責：迄不得早於起。
  - 格式：

```json
"dateRanges": [
  {
    "groupCode": "INCOME_PERIOD",
    "groupName": "所得期間",
    "startFieldCode": "HDR_PERIOD_START",
    "endFieldCode": "HDR_PERIOD_END"
  }
]
```

- 各表不另外逐份描述，後端統一處理。

### 通用結構（表 2、表 3、表 5 及其後各表共用，**以此處為準**）

各表只列自己的差異，不重複定義。若某表與此處不一致，以此處為準並修正該表。

#### G1 欄位屬性

| 屬性 | 型別 | 說明 |
|------|------|------|
| `displayName` | string | **所有欄位都要回**。照紙本印出的文字（含紙本印的「加：」「減：」前綴），去掉「－帳載結算金額」「－自行依法調整後金額」「第 N 列」等後綴／前綴；沒有後綴的欄位等於 `fieldName` |
| `refNo` | string / null | 紙本格內印的圈號（①②③⑦⑨⑩…），是紙本算式互相引用的號碼，不是欄位代碼；名稱（`fieldName`、`displayName`）不再帶「(1)」「(9)」。沒有給 `null` |
| `hidden` | boolean | `true`＝紙本沒有這個欄位：值照常存取（讀取、儲存、送出都保留），但前端不畫；預設 `false`。與 `visibleWhen` 不同：`visibleWhen` 是條件成立才顯示，`hidden` 是紙本上從來沒有 |
| `isDeduction` | boolean | 減項的語意標記（紙本沒印「減：」的也要標）。前端只用來在金額欄標示減項，名稱一律以 `displayName` 為準，不自行加「減：」 |
| `rowCode` | string | 同一列的共同代號，如 `INC_01`；BOOK 與 ADJ 共用。單欄欄位可省略，省略時等於 `fieldCode`（`parentRowCode` 與算式運算元都以此為準） |
| `column` | `"BOOK"` / `"ADJ"` / null | 帳載結算金額欄、自行依法調整後金額欄；單欄為 null |
| `layout` | `"row"` / `"inline"` / `"cell"` / `"text"` | `row`＝一般列（預設）；`inline`＝嵌在別列標題內的空格；`cell`＝表格格子（含 `isRow` 明細表的格子）；`text`＝段落內空格（被 `{{field:…}}` 引用的欄位）；`group`＝表格分組欄位（如財產目錄的類別編號、類別名稱），不佔欄，畫在分組標題列 |
| `labelTemplate` | string / null | 列標題模板，空格用 `{{field:fieldCode}}`，勾選用 `{{group:groupCode}}`。只放在該列第一個欄位，同列其他欄位為 null |
| `note` | string / null | 紙本標題後的括號備註，如「請填第4頁明細表」 |
| `parentRowCode` | string / null | `layout = inline` 時指向主列的 `rowCode` |
| `parentFieldCode` | string / null | 欄位對欄位的從屬，如說明欄指向主欄位 |
| `groupCode` | string / null | 區塊內分組（如調節說明的加項、減項） |
| `visibleWhen` | object / null | `{ "fieldCode": "...", "op": "checked" \| "unchecked" \| "nonZero" }`，條件成立才顯示 |
| `formula` | object / null | 見 G2 |
| `tableCode`／`rowNo`／`columnCode` | string／number 或 string／string | `layout = cell` 時使用，見 G3 |
| `dataType: 6` | number | 百分比，允許負值，顯示值（20 代表 20%） |

規則：

- `fieldCode` 是唯一鍵。`officialFieldCode` 是紙本編號，**同一張表內可以重複**（紙本本身會重複使用同一個代號，例如同一個金額在摘要區與合計列各出現一次），前端不得用它當 key。
- 紙本印有編號的欄位 `officialFieldCode` 一律回傳；紙本沒有編號的維持 `null`。
- 紙本以斜線表示不可填的格子：**不要回傳該欄位**，前端遇到表格內沒有欄位的格子就畫斜線。
- `sectionCode: null`：紙本沒有標題的欄位，前端不顯示標題與卡片外框。
- 前端顯示順序一律依後端回傳順序；section 依其第一個欄位在 `fields[]` 出現的位置排序。

#### G2 算式 `formula`

```json
"formula": { "text": "01－02－03", "expr": "INC_01 - INC_02 - INC_03" }
```

- `text`：紙本上的算式文字，前端原樣顯示（如「營業收入淨額（01－02－03）」）。
- `expr`：計算式。運算元用 `rowCode`（欄位有 `rowCode` 時，BOOK 欄只取 BOOK 欄、ADJ 欄只取 ADJ 欄），沒有 `rowCode` 就用 `fieldCode`。
- 語法：`+ - * /`、括號、比較（`<` `<=` `>` `>=` `==`）、`SUM(A:B)`、`IF(條件, 值1, 值2)`、`MIN`、`MAX`、`FLOOR`。`A:B` 為 `fields[]` 回傳順序中從 A 到 B（含兩端）的欄位，只計入存在的欄位。
- 沒有欄位的格子（斜線）、空值都視為 0。
- `isRow: true` 明細欄位出現在 `SUM(…)` 內，代表該欄**所有資料列**加總（如投資人明細合計列）。
- `formula.scope`：`"table"`（預設，`SUM(…)` 加總整張表的資料列）／`"group"`（表格有 `groupBy` 時，只加總同一類別內的資料列）。
- 帶 `formula` 的欄位必為 `isSubtotal: true`，由後端算出，前端唯讀顯示，**前端不計算**。同一列的兩個欄位（BOOK、ADJ）都帶相同的 `formula`。

#### G3 表格 `tables[]`

metadata 頂層陣列，每張表一筆：

```json
{
  "tableCode": "AMT_LOSS_SEC",
  "title": "前5年證券及期貨交易淨損失減除金額明細表",
  "note": null,
  "sectionCode": "BASE",
  "placeAfter": "TB_AMT_02",
  "rowRepeatable": false,
  "columns": [
    { "columnCode": "LOSS", "title": "證券及期貨交易淨損失", "groups": [] },
    { "columnCode": "USED_PRIOR", "title": "截至上年度已減除金額", "groups": ["已減除金額"] }
  ],
  "rows": [
    { "rowNo": 109 },
    { "rowNo": "TOTAL" }
  ]
}
```

| 屬性 | 說明 |
|------|------|
| `columns[].groups` | 該欄上方的合併表頭，**由上到下**的字串陣列；沒有合併表頭給 `[]`。多層例：`["投資額(4)", "技術或智慧財產權作價"]` |
| `columns[].refNo` | 欄標題旁印的圈號（如表 12「購買國外勞務給付額 ⑬」）；沒有給 `null` 或省略 |
| `columns[].officialFieldCode` | 欄標題旁的紙本編號（如表頭印的「(13)」「(一)」），前端顯示在標題後面；沒有編號給 `null` 或省略 |
| `corner` | 表格左上角斜線格的兩個標題，`{ "column": "項目", "row": "所得類別" }`（任一個沒有就給 `null`）；沒有斜線格省略 |
| `rowNumber` | 序號欄：`{ "title": "編號", "pad": 0 }`。前端依資料列順序自動顯示序號（`pad` 為補零位數，`0`＝1、2、3…，`2`＝01、02…），**不是欄位、不填寫、不送出**；`title` 是欄標題，紙本沒印給 `null`；沒有序號欄省略 |
| `groupBy` | 資料列分組：`{ "fieldCodes": [分組欄位], "headerTemplate": "{{field:…}} {{field:…}}", "subtotalLabel": "小計：" }`。前端依分組欄位把明細列分組，每組上方畫標題列（`headerTemplate`）、下方畫小計列；小計格的欄位 `rowNo` 為 `"SUBTOTAL"`；沒有分組省略 |
| `rows[].rowGroup` | 跨列的列標題（如表二「利息收入」跨兩列）：`rowGroup` 相同且相鄰的列，前端把列標題合併成一格；沒有給 `null` 或省略 |
| `rows` | 列清單，每筆 `{ "rowNo": number 或 string, "rowLabel": string 或省略 }`。`rowNo` 為 `"TOTAL"` 表示合計列；`rowLabel` 是列標題文字（如免稅所得的項次說明） |
| `rowRepeatable` | `true` 表示使用者可以新增列（`isRow` 明細表，如投資人明細）；此時 `rows` 只放 `TOTAL`（若有合計列），資料列由使用者新增 |
| `placeAfter` | 顯示位置，見下方「版面順序」；省略代表放在該 section 最後 |
| 格子欄位 | `fields[]` 內 `layout: "cell"`，帶 `tableCode`、`rowNo`、`columnCode`。合計列格子的紙本編號放在 `officialFieldCode`，前端顯示在格子左上角 |

#### G4 段落 `textBlocks[]`

紙本中「一段文字，中間夾著編號與空格」的項目：

```json
{
  "blockCode": "TB_122",
  "sectionCode": null,
  "officialFieldCode": "122",
  "placeAfter": null,
  "template": "所得稅費用（利益）{{field:INC_122}} 元（請附明細表）。"
}
```

| 代號 | 意義 |
|------|------|
| `{{field:fieldCode}}` | 可輸入的欄位（該欄位 `layout: "text"`） |
| `{{ref:fieldCode}}` | 引用其他欄位的值，唯讀 |
| `{{group:groupCode}}` | 一組勾選（`choiceGroups` 的 `groupCode`），畫成行內勾選框 |

- `labelTemplate`（G1）只能用 `{{field:…}}`、`{{group:…}}`，不用 `{{ref:…}}`。
- 一個段落內有多個編號時，以各欄位自己的 `officialFieldCode` 為準，`textBlocks` 的 `officialFieldCode` 為 null。
- `textBlocks` 的 `sectionCode` 要與其內含欄位的 `sectionCode` 一致。

#### G5 版面順序（`placeAfter`）

- 同一 section 內：沒有被 `textBlocks`／`tables` 引用的 `row` 欄位依 `fields[]` 順序畫成列；`textBlocks`、`tables` 依 `placeAfter` 決定位置。
- `placeAfter` 的值可以是 `"TOP"`（放在該 section 最前面）、某個 `blockCode`、`tableCode` 或 `fieldCode`（接在它後面）；`null` 或省略代表放在該 section 最後，多筆時依陣列順序。

#### G6 算式語法

`formula.expr` 一律使用 G2 定義的語法輸出，各表不另外約定其他語法。

- `columns[].title` 一律是紙本印出的文字（含「（－）」「（＋）」「（＝）」等符號）。

#### G7 區塊標題 `sections[]`

metadata 頂層陣列，每個區塊一筆：

```json
{ "sectionCode": "PAY", "title": "表一、114年度各類給付扣繳、股利憑單金額與申報金額調節", "parentSectionCode": null }
```

- `title` 是紙本印出的**完整標題**（含「表一、」等編號與左側直書標題），不簡寫；年度由後端依 `taxYear` 帶入。
- 紙本沒有標題的區塊不回傳；需要巢狀的無標題子區塊回傳 `title: null`。
- `parentSectionCode`：子區塊畫在父區塊底下（標題層級較小）；沒有父區塊給 `null`。
- 區塊內表格的標題用 `tables[].title`；表格標題與區塊標題相同時只回傳區塊標題，表格 `title: null`。
- 前端一律取 `sections[]` 顯示標題，不再自行對照簡稱。

#### G8 勾選群組 `choiceGroups[]`

沿用現有 `groupCode`、`groupName`、`maxSelect`、`fieldCodes`，新增：

| 屬性 | 說明 |
|------|------|
| `officialFieldCode` | 群組的紙本編號（題號）；沒有給 `null` |
| `note` | 群組後的括號提示（如「本題勾選「是」者，免填…」）；沒有給 `null` |
| `columns` | 勾選框每列並排幾個（如紙本兩欄排列給 `2`）；省略自動排列 |
| `display` | `"checkbox"`：每個成員畫成一個勾選框並排（紙本樣式），`maxSelect` 為 1 時保持互斥；省略代表前端自行決定呈現方式 |

規則：

- `groupName` 是紙本完整的題目或標題，不簡寫。
- 是／否這類成員的 `displayName` 為「是」「否」，`officialFieldCode` 為 `null`（編號由群組帶）。

## 前端修改記錄（全域，2026-11-10 核對：5 項前端皆已實作）

下列是前端配合的全域調整，各表的細項見各表的「前端配合事項」。5 項已在 PaperForm 渲染（`paperLayout.ts`、`paper/*`）落實，不再依賴已移除的 `sectionTitles.ts`、`PaperFormView.tsx`；畫面上仍看到的「表頭」等標題是後端 `sections[].title` 回傳的，不是前端寫死。

1. **沒有名稱的區塊不顯示任何文字**（例如表頭）。區塊標題一律取後端 `sections[]` 的 `title`，沒有 `title` 就不渲染標題；現有 `src/features/initialization/reports/sectionTitles.ts` 的簡稱對照（如 `HEADER` 的「表頭」）要移除。
2. **盡量與原始表單一致：二選一勾選畫成勾選框**，不使用灰底分段切換（tab）元件。`choiceGroups[].display: "checkbox"` 時，成員並排畫成勾選框並維持互斥；目前 `reports/index.ts` 的 `buildReportPage` 與 `ReportChoiceField` 把 3 項以內的群組合併成 tab 元件，要改。
3. **不顯示加減等於符號**：列首的「－」「＋」「＝」徽章與 `＝` 小計列的淡藍底標示一律拿掉。位置：`components/PaperFormView.tsx`（`main.isSubtotal ? '＝' : main.isDeduction ? '−' : ''`）、`components/VatFormView.tsx`（同樣的 operator）；`BalanceSheetView.tsx` 的「減：」前綴也要檢查。名稱照紙本 `displayName`，`isDeduction` 只做語意標記。
4. **金額欄位允許負值**：`buildReportPage` 對所有 `money` 欄位開啟 `allowSign`；`ReportAmountInput`、`BalanceSheetView` 補傳 `allowSign`；小數欄（百分比）輸入允許 `-`。
5. **`dataType: 6`（百分比）**：補上型別對應、辨識回填（`pickIdentifiedValue`）與送出（`confirmPayload`）。

## 表 2　損益及稅額計算表

- 表單：`formCode = CIT_INCOME_TAX`、`formNo = 2`、`officialFormCode = 1`、`taxYear = 114`
- 對照基準：`public/form-previews/cit-income-tax.webp`（114 年度第 1 頁紙本）
- 目標：前端**直接照紙本版型呈現**，所以 metadata 要能表達「同一列的雙欄金額」「標題內的空格」「段落中間的空格」「表格」「勾選後出現輸入框」「算式」「欄位編號」。

### 2.0 設計原則

- 沿用現有 `fields[]`、`choiceGroups[]`，**只新增屬性**，不拿掉現有屬性。
- 新增兩個頂層陣列：`tables[]`（表格）、`textBlocks[]`（段落帶空格）。
- 小計、比率、稅額一律由後端計算。`formula` 只負責「告訴前端怎麼顯示算式」，前端不自己加總。
- 紙本上印有編號的欄位，`officialFieldCode` 一律回傳。紙本沒編號的（如行內附帶金額）維持 `null`。

---

### 2.1 欄位新增屬性

屬性定義見文件開頭「通用結構」G1～G5，本表不另外定義。本表用到的屬性：`displayName`、`rowCode`／`column`、`layout`（`row`、`inline`、`cell`、`text`）、`labelTemplate`、`note`、`parentRowCode`、`parentFieldCode`、`groupCode`、`visibleWhen`（`checked`、`nonZero`）、`formula`、`tables[]`、`textBlocks[]`、`dataType: 6`。

---

### 2.2 一般列：雙欄金額、行內附帶金額、編號

#### 2.2.1 雙欄配對

紙本每列左邊是項目名稱＋編號，右邊是兩個金額欄（帳載結算金額、自行依法調整後金額）。後端回傳時：

### 2.11 辨識吃到編號（後端辨識調整）

#### 營業收入分類表

紙本此表每列「標準代號」「營業收入淨額」格子左上角已印有欄位編號（89、90、91、92、94、96、138、139），填寫值在編號後面。目前辨識結果會把印刷編號吃進欄位值。

- 辨識這 8 個格子時，要忽略格內預先印刷的欄位編號，只取使用者填寫的內容。
- 編號只作為欄位對應（`officialFieldCode`），不得併入 `value`。
- 受影響欄位：`INC_89`、`INC_90`、`INC_91`、`INC_92`、`INC_94`、`INC_96`、`INC_138`、`INC_139`。
- 空白格要回空值，不能回編號本身。
- 其他「編號印在格內」的欄位（稅額欄 112、119、95、118、113、62、63、135、64、65、116、117）也請檢查有沒有同樣被吃進值。

驗收：拿一張 `RATES` 全空白與一張有填寫的紙本各跑一次，空白回空值，有填寫只回填寫內容。

#### 其他可能被吃進去的編號

行內文字中的編號（如「包括 97 退稅收入」的 97、「127」「130」「122」「123」「124」）是標題或段落文字的一部分，不是欄位值，辨識時不要當成金額。

### 2.14 前端渲染對照

| 後端屬性 | 畫面呈現 |
|----------|----------|
| `rowCode` + `column` | 同一列：左邊「編號 名稱」，右邊帳載、調整後兩個金額欄 |

#### 11.6.2 算式

運算元沿用 G2（沒有 `rowCode` 的欄位用 `fieldCode`）。以下欄位 `isSubtotal: true`，由後端算，前端唯讀。`formula.text` 照紙本格內與項目欄印的文字。

| 欄位（代碼） | `formula.text` | `formula.expr` |
|--------------|----------------|----------------|
| `OUT_TAXABLE_SALES_SUM`（21①） | 1＋5＋9＋13－17 | `OUT_INV3_SALES + OUT_EINV_SALES + OUT_INV2_SALES + OUT_NO_INV_SALES - OUT_ALLOWANCE_SALES` |
| `OUT_TAXABLE_TAX_SUM`（22②） | 2＋6＋10＋14－18 | `OUT_INV3_TAX + OUT_EINV_TAX + OUT_INV2_TAX + OUT_NO_INV_TAX - OUT_ALLOWANCE_TAX` |
| `OUT_ZERO_SALES_SUM`（23③） | 3＋7＋11＋15－19 | `OUT_INV3_ZERO + OUT_EINV_ZERO + OUT_INV2_ZERO + OUT_NO_INV_ZERO - OUT_ZERO_ALLOWANCE_SALES` |
| `OUT_SALES_GRAND_TOTAL`（25⑦） | ①＋③ | `OUT_TAXABLE_SALES_SUM + OUT_ZERO_SALES_SUM` |
| `IN_PURCHASE_AMT_SUM`（44） | 28＋32＋36＋78－40 | `IN_GUI_PURCHASE_AMT + IN_EINV_PURCHASE_AMT + IN_OTHER_PURCHASE_AMT + IN_CUSTOMS_PURCHASE_AMT - IN_ALLOWANCE_PURCHASE_AMT` |
| `IN_PURCHASE_TAX_SUM`（45⑨） | 29＋33＋37＋79－41 | `IN_GUI_PURCHASE_TAX + IN_EINV_PURCHASE_TAX + IN_OTHER_PURCHASE_TAX + IN_CUSTOMS_PURCHASE_TAX - IN_ALLOWANCE_PURCHASE_TAX` |
| `IN_ASSET_AMT_SUM`（46） | 30＋34＋38＋80－42 | `IN_GUI_ASSET_AMT + IN_EINV_ASSET_AMT + IN_OTHER_ASSET_AMT + IN_CUSTOMS_ASSET_AMT - IN_ALLOWANCE_ASSET_AMT` |
| `IN_ASSET_TAX_SUM`（47⑩） | 31＋35＋39＋81－43 | `IN_GUI_ASSET_TAX + IN_EINV_ASSET_TAX + IN_OTHER_ASSET_TAX + IN_CUSTOMS_ASSET_TAX - IN_ALLOWANCE_ASSET_TAX` |
| `TAX_OUTPUT_TOTAL`（101） | ② | `OUT_TAXABLE_TAX_SUM` |
| `TAX_INPUT_DEDUCTIBLE`（107） | ⑨＋⑩ | `IN_PURCHASE_TAX_SUM + IN_ASSET_TAX_SUM` |
| `TAX_DEDUCTIBLE_SUBTOTAL`（110） | 7＋8 | `TAX_INPUT_DEDUCTIBLE + TAX_PRIOR_CREDIT` |
| `TAX_PAYABLE`（111） | 1－10 | `MAX(0, TAX_OUTPUT_TOTAL - TAX_DEDUCTIBLE_SUBTOTAL)` |
| `TAX_CURRENT_CREDIT`（112） | 10－1 | `MAX(0, TAX_DEDUCTIBLE_SUBTOTAL - TAX_OUTPUT_TOTAL)` |
| `TAX_REFUND_LIMIT`（113） | ③×5%＋⑩ | `OUT_ZERO_SALES_SUM * 5 / 100 + IN_ASSET_TAX_SUM` |
| `TAX_REFUND`（114） | 如 12>13 則為 13，13>12 則為 12 | `MIN(TAX_CURRENT_CREDIT, TAX_REFUND_LIMIT)` |
| `TAX_CARRY_CREDIT`（115） | 12－14 | `TAX_CURRENT_CREDIT - TAX_REFUND` |

- `TAX_PRIOR_CREDIT`（108）是使用者填寫的欄位，不是算式。
- 111、112 紙本只寫「1－10」「10－1」，兩者互斥，負數以 0 計（`MAX(0, …)`）。
- 5% 是算式常數，不是百分比欄位。
- 金額欄位允許負值（見全域規格）。

| `AMOUNT` | 購買國外勞務給付額 | ⑬ | `IN_FOREIGN_SERVICES` | 74 | 使用者填寫 |
| `VAT` | 營業稅額 | ⑭ | `IN_FOREIGN_SERVICES_VAT` | 75 | 算式，`formula.text`：⑭＝⑬×稅率 |

### 12.6 稅額計算表與算式

#### 12.6.1 表格

`tableCode: VAT_TAX`，`rowNo` 為紙本項次，單一欄「稅額」（同表 11 的 11.6.1）：

| `rowNo` | `rowLabel` | `fieldCode` | `officialFieldCode` |
|---------|------------|-------------|---------------------|
| 1 | 本期(月)銷項稅額合計 | `TAX_OUTPUT_TOTAL` | 101 |
| 3 | 購買國外勞務應納稅額 | `TAX_FOREIGN_SERVICES` | 103 |
| 4 | 特種稅額計算之應納稅額 | `TAX_SPECIAL` | 104 |
| 5 | 中途歇業年底調整補徵應繳稅額（詳附表） | `TAX_MIDYEAR_PAYABLE` | 105 |
| 6 | 小計(1.＋3.＋4.＋5.) | `TAX_SUBTOTAL_OUTPUT` | 106 |
| 7 | 得扣抵進項稅額合計 | `TAX_INPUT_DEDUCTIBLE` | 107 |
| 8 | 上期(月)累積留抵稅額 | `TAX_PRIOR_CREDIT` | 108 |
| 9 | 中途歇業年底調整應退稅額（詳附表） | `TAX_MIDYEAR_REFUND` | 109 |
| 10 | 小計(7.＋8.＋9.) | `TAX_DEDUCTIBLE_SUBTOTAL` | 110 |
| 11 | 本期(月)應實繳稅額(6.－10.) | `TAX_PAYABLE` | 111 |
| 12 | 本期(月)申報留抵稅額(10.－6.) | `TAX_CURRENT_CREDIT` | 112 |

| 14 | 本期(月)應退稅額(如 12.>13. 則為 13.，13.>12. 則為 12.) | `TAX_REFUND` | 114 |
| 15 | 本期(月)累積留抵稅額(12.－14.) | `TAX_CARRY_CREDIT` | 115 |

`TAX_MIDYEAR_PAYABLE`（105）、`TAX_MIDYEAR_REFUND`（109）、`TAX_PRIOR_CREDIT`（108）是使用者填寫的欄位，不是算式。

#### 12.6.2 算式

銷項（21①、22②、23③ 同表 11 的 11.6.2；24④ 新增）：

| 欄位（代碼） | `formula.text` | `formula.expr` |
|--------------|----------------|----------------|
| `OUT_EXEMPT_SALES_SUM`（24④） | 4＋8＋12＋16－20 | `OUT_INV3_EXEMPT + OUT_EINV_EXEMPT + OUT_INV2_EXEMPT + OUT_NO_INV_EXEMPT - OUT_EXEMPT_ALLOWANCE` |
| `SP_SALES_SUM`（65⑤） | 52＋54＋84＋56＋60＋62－63 | `SP_FOOD_25_SALES + SP_FOOD_15_SALES + SP_BANK_5_SALES + SP_FIN_2_SALES + SP_REINSURE_SALES + SP_EXEMPT_INCOME - SP_ALLOWANCE_SALES` |
| `SP_TAX_SUM`（66⑥） | 53＋55＋85＋57＋61－64 | `SP_FOOD_25_TAX + SP_FOOD_15_TAX + SP_BANK_5_TAX + SP_FIN_2_TAX + SP_REINSURE_TAX - SP_ALLOWANCE_TAX` |
| `OUT_SALES_GRAND_TOTAL`（25⑦） | ①＋③＋④＋⑤ | `OUT_TAXABLE_SALES_SUM + OUT_ZERO_SALES_SUM + OUT_EXEMPT_SALES_SUM + SP_SALES_SUM` |

進項與扣抵：

| 欄位（代碼） | `formula.text` | `formula.expr` |
|--------------|----------------|----------------|
| `IN_PURCHASE_AMT_SUM`（44）、`IN_PURCHASE_TAX_SUM`（45⑨）、`IN_ASSET_AMT_SUM`（46）、`IN_ASSET_TAX_SUM`（47⑩） | 同表 11 的 11.6.2 | 同表 11 |
| `IN_NONDEDUCT_RATIO`（50⑪） | （④＋⑤－⑧）／（⑦－⑧） | `(OUT_EXEMPT_SALES_SUM + SP_SALES_SUM - OUT_LAND_SALES) / (OUT_SALES_GRAND_TOTAL - OUT_LAND_SALES) * 100` |
| `IN_DEDUCTIBLE_TAX`（51⑫） | （⑨＋⑩）×（1－⑪） | `(IN_PURCHASE_TAX_SUM + IN_ASSET_TAX_SUM) * (1 - IN_NONDEDUCT_RATIO / 100)` |
| `IN_FOREIGN_SERVICES_VAT`（75） | ⑭＝⑬×稅率 | `IN_FOREIGN_SERVICES * 5 / 100` |
| `IN_FOREIGN_SERVICES_PAYABLE`（76⑱） | ⑮＝⑭×⑪ | `IN_FOREIGN_SERVICES_VAT * IN_NONDEDUCT_RATIO / 100` |

稅額計算：

| 欄位（代碼） | `formula.text` | `formula.expr` |
|--------------|----------------|----------------|
| `TAX_OUTPUT_TOTAL`（101） | ② | `OUT_TAXABLE_TAX_SUM` |
| `TAX_FOREIGN_SERVICES`（103） | ⑱ | `IN_FOREIGN_SERVICES_PAYABLE` |
| `TAX_SPECIAL`（104） | ⑥ | `SP_TAX_SUM` |
| `TAX_SUBTOTAL_OUTPUT`（106） | 1.＋3.＋4.＋5. | `TAX_OUTPUT_TOTAL + TAX_FOREIGN_SERVICES + TAX_SPECIAL + TAX_MIDYEAR_PAYABLE` |
| `TAX_INPUT_DEDUCTIBLE`（107） | ⑫ | `IN_DEDUCTIBLE_TAX` |
| `TAX_DEDUCTIBLE_SUBTOTAL`（110） | 7.＋8.＋9. | `TAX_INPUT_DEDUCTIBLE + TAX_PRIOR_CREDIT + TAX_MIDYEAR_REFUND` |
| `TAX_PAYABLE`（111） | 6.－10. | `MAX(0, TAX_SUBTOTAL_OUTPUT - TAX_DEDUCTIBLE_SUBTOTAL)` |
| `TAX_CURRENT_CREDIT`（112） | 10.－6. | `MAX(0, TAX_DEDUCTIBLE_SUBTOTAL - TAX_SUBTOTAL_OUTPUT)` |
| `TAX_REFUND_LIMIT`（113） | ③×5%＋⑩ | `OUT_ZERO_SALES_SUM * 5 / 100 + IN_ASSET_TAX_SUM` |
| `TAX_REFUND`（114） | 如 12.>13. 則為 13.，13.>12. 則為 12. | `MIN(TAX_CURRENT_CREDIT, TAX_REFUND_LIMIT)` |
| `TAX_CARRY_CREDIT`（115） | 12.－14. | `TAX_CURRENT_CREDIT - TAX_REFUND` |

以上欄位 `isSubtotal: true`，值由後端算，前端唯讀。5% 是算式常數，不是百分比欄位。111、112 紙本只寫「6.－10.」「10.－6.」，兩者互斥，負數以 0 計。金額欄位允許負值（全域規格）。

### 12.7 退稅處理、附件、申辦情形

- **退稅處理**：`REFUND_BANK_TRANSFER`（利用存款帳戶劃撥）、`REFUND_CHECK`（領取退稅支票）已存在；`VAT_REFUND` 的 `groupName` 改「本期(月)應退稅額處理方式」，加 `display: "checkbox"`。
