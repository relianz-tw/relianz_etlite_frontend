# 新增文件：各類所得扣繳暨免扣繳憑單申報書（第 13 份）

整理日期：2026-11-11。對照紙本：`public/form-previews/各類所得扣繳暨免扣繳憑單申報書.jpg`（紙本「表單編號 A」）。

## 背景

開帳流程的營所稅文件需要新增「各類所得扣繳暨免扣繳憑單申報書」（簡稱：各類所得扣繳申報書），目前 `/ael/peit/form/metadata`、`/ael/peit/cit/identify`、`/ael/peit/form/confirm` 都沒有。
請比照既有 12 份文件（見 `docs/開帳文件修改.md` 的 G1～G5 通用結構）新增第 13 份，以下為依紙本整理的欄位規格。`formNo`、`formCode`、`fieldCode` 命名由後端決定，下列為建議。

- 建議 `formNo: 13`、`formCode: CIT_WH_RETURN`、`formName: 各類所得扣繳暨免扣繳憑單申報書`、`officialFormCode: A`、`taxType: 0`（營所稅）。
- 年度：與其他營所稅文件相同（開帳年度 −1，例如開帳 115 → 114 年度）。
- 所有金額欄位（`dataType: 1`）允許負值（全域規格）；顯示順序一律依 `fields[]` 回傳順序。

## 2. 區分：境內居住之個人或在境內有固定營業場所之營利事業（`choiceGroups[]`）

紙本表格左側「區分」欄印「1□是　2□否」，旁邊是文字「境內居住之個人或在境內有固定營業場所之營利事業」（適用者以✓表示，並分別填造本申報書）。

- 建議 `groupCode: WH_RESIDENT`、`maxSelect: 1`，成員 `WH_RESIDENT_YES`（`officialFieldCode: "1"`、`displayName: 是`）、`WH_RESIDENT_NO`（`"2"`、`否`），
  `groupName` 用紙本文字「境內居住之個人或在境內有固定營業場所之營利事業」。（資料型別：布林，4。）

## 5. 辨識（identify）與送出（confirm）

- `identify`：`forms[]` 加入這份文件，欄位以 `fieldCode`、`rowNo`／`columnCode` 回傳。
- `confirm`：同其他文件，固定欄位走 `fields[]`，這份只有固定格子沒有可重複列。
- 是否為必填、選填：與其他營所稅文件相同（選填，沒有可略過）。

## 前端處理

後端提供 metadata 後，前端把這份文件加入文件清單（順序依產品：排在 401／403 之後，即各類所得扣繳申報書），並沿用現有的紙本表格版型；
不需要另外開發。formNo 確定後請告知，前端需要在文件清單登記 `formNo`、`formCode`。
